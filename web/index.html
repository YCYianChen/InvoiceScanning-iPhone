發票記帳

登入後，網頁版和 iPhone App 的發票會自動同步。

尚未設定雲端同步 請先依 README 建立 Firebase 專案，並把設定填進 web/firebase-config.js。

發票存在你的帳號裡（Google Firebase），傳輸和儲存都有加密。資料庫的安全規則只允許你本人登入後讀寫自己的發票，其他使用者看不到。

設定與備份

帳號

會永久刪除帳號和雲端上所有發票，網頁版和 App 都會一起消失。建議先匯出備份。

備份

關於資料

發票存在你的帳號裡，網頁版和 iPhone App 登入同一個帳號就會同步。沒有網路時也能新增，連上網路後會自動上傳。 想多一層保險，可以定期匯出備份檔存到「檔案」或 iCloud Drive。
